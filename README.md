# ziyuanAI · ComfyUI 图片与视频节点

在 ComfyUI 中通过 [ziyuanAI](https://ziyuanai.cn) 调用云端图片和视频模型。支持图片、视频、音频参考，统一视频模型切换，以及普通和异步生成。

需要网站账号、可用 API 令牌及对应模型额度；生成请求按网站规则计费。参考素材会发送至所配置的 API 服务。插件不在本机运行生成模型，视频功能需要支持原生 VIDEO 类型的 ComfyUI。

## 统一视频节点

同一个“ziyuanAI. 视频生成”节点切换以下四个模型；异步模式使用“视频异步提交 → 视频异步获取”。

| 模型 | 分辨率 | 时长 | 参考图 | 参考视频 | 参考音频 |
| --- | --- | --- | --- | --- | --- |
| omni-flash-components | 720p / 1080p | 1–60 秒，真实服务范围待实测 | 最多14张 | 不支持 | 不支持 |
| doubao-seedance-2.0 | 480p / 720p / 1080p / 4k | 4–15整数秒 | 最多9张 | 最多3段 | 最多3段，每段2–15秒，须搭配图片或视频 |
| doubao-seedance-2.0-mini | 仅720p | 4–15整数秒 | 最多9张 | 最多3段 | 最多3段，每段2–30秒，须搭配图片或视频；上游效果待验证 |
| doubao-seedance-2.5 | 480p / 720p / 1080p | 4–15整数秒 | 全部素材合计最多12个 | 全部素材合计最多12个 | 最多10段，每段2–30秒；可仅音频加提示词 |

三个 Doubao 模型的素材总数均不得超过12，包括 IMAGE/AUDIO 批次和远程链接。2.5 仅采用中转文档公布的总数上限，不承诺12段视频一定通过上游容量限制。固定比例：16:9、9:16、1:1、4:3、3:4、21:9；Mini 另支持自动（adaptive）。三个模型均显示“生成声音”开关，默认开启。声音开关控制成片声音，与参考音频能力不同。

已移除 `seedance-2.5v5`、`seedance-2.0-fast-1080p`、`jimeng-2.5-480p`、`jimeng-2.5-720p` 的选择项和适配代码。使用这些旧模型的工作流需要手动选择新模型，不会自动替换后提交。图片模型和图片数量修复保留。

## 图片、视频、音频直接连接

“加载图像”的 IMAGE 输出接“参考图”；原生“加载视频”的 VIDEO 输出接“参考视频”。原生“加载音频（LoadAudio）”的 AUDIO 输出接“参考音频”。IMAGE 帧序列须先经“创建视频”转换为 VIDEO。默认只显示各类型第一个空输入口，接入后展开下一个；断开中间连线时，后续素材按顺序前移、连续编号。图片节点沿用相同规则。

切换模型后自动调整分辨率、比例、时长。已有连线保留；不受新模型支持的连线标注“请断开”，后端拒绝执行，避免静默漏掉素材。保存、恢复工作流同步保留素材顺序。

Doubao 的“素材模式”有两种：

- 组合参考：按各自编号顺序发送图片、视频、音频；无需素材时即文生视频。
- 首尾帧：参考图1为首帧，参考图2为可选尾帧。最多两张图片，含批次；不得混用视频或参考音频。

图片转换为 PNG，每张最多10 MiB；视频转换为 MP4，每段最多50 MiB、时长大于0且不超过15秒。不会自动裁剪素材。中转站及 Nginx 的总请求体限制仍可能更小。

三个 Doubao 模型均支持本地 AUDIO 连线，转为 PCM 16-bit WAV 后每段最多15 MiB，保留单/双声道和采样率。时长按每个 AUDIO 批次中的每段分别校验，不截短音频；音频时长不改变生成视频的时长。Mini 的旧音频链接接受 HTTPS 或 asset://。旧工作流填写的图片/视频/音频链接保留，并在非空时显示供清理；新工作流直接连素材即可。同类素材不能同时填写旧链接和连接本地输入。2.0/2.5 的旧链接必须是带 expires/signature 的巧模 `/api/reference/` 签名链接。

为兼容旧 Mini 工作流，素材模式及链接字段的内部名称仍以 Mini 开头；界面标签去掉此前缀。超过所选模型上限的已连插口保留并明确报错。首尾帧模式收起空的音频/视频口，已有连线标注需要断开。如果旧节点缺少新控件，请重新添加统一视频节点并接线。

## API 兼容要求

默认 API 地址为 `https://ziyuanai.cn`，使用该网站颁发的 API 令牌。自定义 API 地址必须兼容本插件的图片和视频接口；通用聊天接口不能替代视频接口。

Doubao 视频适配 `qiaomo-seedance` 0.4.1 契约：Mini 仅支持720p；本地音频上传要求服务端具有0.4.0音频上传能力。使用其他网关前，请确认模型名称、素材上传、任务轮询及结果下载均兼容。插件不管理服务端渠道、售价或余额。

- 图片：`POST /v1/images/generations`；参考图使用 `/v1/images/edits`。
- 视频：`POST /v1/videos`，查询 `/v1/videos/{task_id}`，下载返回地址或 `/v1/videos/{task_id}/content`。
- Doubao 的图片、视频、音频使用 multipart 文件上传，参数放在 metadata；首尾帧使用独立文件字段。

## 节点与异步任务

仅保留6个节点：图片生成、图片异步提交、图片异步获取、视频生成、视频异步提交、视频异步获取。图片模型为 gpt-image-2、gpt-image-2.5-flare、gpt-image-2.5-sunburst，最多14张参考图。

图片参数包含提示词、模型、比例、分辨率（1K/2K/4K）、质量、输出格式、生成数量及公共设置。图片“自动”比例沿用第一张参考图，无参考图按1:1。质量/格式默认自动，不额外发送参数。

异步提交立即返回本地任务编号，在同一个 ComfyUI 进程中交给对应获取节点。最多同时运行2个任务，最多保留32个记录；重复获取保留的结果不会重复请求。重启后本地任务编号失效，应先查网站任务记录，避免重复付费提交。取消获取只停止本地等待，不会取消服务端任务。

示例在 examples：01-image-and-video.json、02-image-async.json、08-unified-video.json、09-unified-video-async.json。视频示例默认 Mini，可切换模型。安装时务必包含 web 目录。

## 安装

1. 下载本仓库的 ZIP 并解压，把插件文件夹放入 `ComfyUI/custom_nodes/`，建议命名为 `comfyui-ziyuan-API`。确认文件夹内直接包含 `__init__.py`、`nodes.py` 和 `web/`。
2. 使用运行 ComfyUI 的 Python 安装 `requirements.txt`。Torch 沿用 ComfyUI 环境，不需要额外安装。
3. 重启 ComfyUI 并刷新浏览器，搜索 **ziyuanAI** 添加节点。

标准 Python 环境，在插件目录运行：

```bash
python -m pip install -r requirements.txt
```

Windows 官方便携包，在便携包根目录运行：

```powershell
.\python_embeded\python.exe -m pip install -r .\ComfyUI\custom_nodes\comfyui-ziyuan-API\requirements.txt
```

其他整合包请使用对应的 Python 路径。更新前备份工作流，然后替换插件文件，重启 ComfyUI 并刷新页面。

## 使用

### 图片

“ziyuanAI. 图片生成” → “预览图像”或“保存图像”。输入提示词、API Key，选择模型即可。需要参考图时，把“加载图像”连接到图片输入口。`生成数量` 是一次请求的图片数量，最大输入值为 10；模型可能有更小限制。

### 视频

“ziyuanAI. 视频生成” → 原生“保存视频（SaveVideo）”节点，可显示视频预览。视频节点已经将下载文件保存到 `ComfyUI/output/ziyuan/`，连接 SaveVideo 会额外保存一份。可连接参考图进行图生视频或多图参考生成。

选择 Omni 时，“比例”和“分辨率”自动换算成 API 的宽高尺寸；“时长秒数”是请求的视频时长。UI 提供的数值范围不是服务能力承诺；尚未通过付费请求核实 Omni 的尺寸、时长和参考图上限。

### 公共设置

- `API地址` 默认 `https://ziyuanai.cn`，也接受以 `/v1` 结尾的地址。
- `API密钥` 填写你网站的 API 令牌。也可以留空，通过启动 ComfyUI 时的 `ZIYUAN_API_KEY` 环境变量提供。直接填写的密钥会随工作流保存，分享工作流前请清空。
- `种子` 仅用于改变 ComfyUI 缓存输入，让同一提示词再次生成。它不发送到模型，也不保证图片复现。需要每次生成时，使用其生成后递增/随机选项。
- `最大等待秒数` 限制本次执行的等待时间。可通过 ComfyUI 的取消按钮停止本地等待；这不会取消服务器已创建的任务，也不会保证退款。
- 请求失败会让节点明确报错。不会输出黑图充当成功结果，也不会自动重发生成请求。超时后请先检查网站任务记录再重试，避免重复计费。
- 返回图片尺寸不一致时会报错，不会自动缩放或裁剪你的结果。

## 测试与已知限制

本地验证通过33项Python测试、20项前端测试，覆盖请求参数、素材数量与时长、音频编码、原生视频解析、异步处理、动态输入口和旧工作流恢复。使用中转插件0.4.1校验了1176种无素材参数组合。

这些测试使用本地模拟服务与合成媒体，不代表所有模型已通过真实生成验收。Omni的服务上限、Mini参考音频效果及实际生成声音需以服务端结果为准。服务可用性、收费及退款由API服务提供方决定。

运行测试时，需要安装ComfyUI依赖的Python环境，并设置 `COMFYUI_PATH` 指向ComfyUI根目录：

```bash
python -m unittest discover -s tests -v
node --test tests/test_unified_video.mjs
```

可选设置 `QIAOMO_PLUGIN_PATH` 指向兼容中转插件0.4.1的 `plugin.js`，用于接口契约校验。未提供对应环境或文件时，相关检查会跳过；中转插件源码不包含在本仓库中。

## 常见问题

- **看不到新节点或模型选项**：确认没有安装重复副本，重启ComfyUI并刷新页面；必要时重新添加节点。
- **Mini不能选择480p**：当前接口仅接受720p，旧工作流界面会自动调整。
- **参考音频报错**：检查模型对应的音频时长、数量和素材模式。2.0/Mini须搭配图片或视频，2.5允许纯音频加提示词。
- **上传失败或HTTP 413**：检查单文件大小及网关总请求体限制，后者可能更小。
- **任务超时**：先在网站查询已有任务，不要立即重复提交，以免重复计费。
- **分享工作流**：先清空API密钥；推荐通过 `ZIYUAN_API_KEY` 环境变量提供密钥。

反馈问题时，请提供模型名称、节点参数、ComfyUI版本和脱敏错误信息，不要上传API密钥。
